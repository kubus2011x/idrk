# Changelog

## 0.1.0 - first prototype
- Full single-player loop: menu -> contract briefing -> shift -> delivery -> results -> next shift / retry.
- Procedural 7x5 facility (maze + loops): kitchens, storage, freezers, dining areas, corridors, loading bay, sliding doors, flickering lights, signs.
- Five cargo types with value/weight, pick up / drop / throw, carry capacity and slowdown.
- Health Inspector enemy: patrol, noise investigation, line-of-sight chase, search, citations, stun by grease and thrown food.
- Grease hazards (player and enemy slip), leaking Mystery Sauce Crate, pushable physics crates/barrels.
- Procedural audio (hum, footsteps, clangs, alarm, chase stinger, PA chime) and IMGUI interface.
- Editor automation: Tools > Shift Meal > Generate Prototype / Open Main Scene / Build Windows (x64).
- Multiplayer: not implemented.
